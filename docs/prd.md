# Автоматизация подготовки расчёта по модулям и опциям

## Что за проект

Инструмент помогает выбрать один или несколько модулей и опций из Excel-файла «Прайс-лист», рассчитывает их стоимость и сохраняет результат в отдельный новый файл.

## Какую проблему решает

Автоматизирует ручной отбор модулей и опций, сокращает время работы с таблицей при подготовке коммерческих предложений и помогает избежать пропущенных цен и повторно выбранных позиций.

## Для кого

Для аккаунт-менеджеров, которые работают с прайс-листом и готовят коммерческие предложения.

## Детали и пожелания

- Для выбора позиций используются отметки напротив нужных модулей и выпадающий список.
- Аккаунт-менеджер может выбрать несколько модулей и опций.
- Новый файл содержит только выбранные позиции, их цены и итоговый расчёт.
- Результат оформляется как упрощённая таблица без лишних данных из исходного прайс-листа.
- Перед созданием файла инструмент проверяет, выбрана ли хотя бы одна позиция, указаны ли цены и нет ли повторов.

## Дорожная карта

1. Добавить выбор модулей и опций с помощью отметок и выпадающего списка.
2. Разрешить одновременный выбор нескольких позиций.
3. Проверить выбор: не допустить пустой результат, отсутствующие цены и повторы.
4. Рассчитать стоимость выбранных позиций и итоговую сумму.
5. Сохранить результат в новый файл в виде упрощённой таблицы.
