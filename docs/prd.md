# Автоматизация подготовки расчёта по модулю

## Что за проект

Инструмент выбирает один модуль из Excel-таблицы и сохраняет расчёт по нему в отдельный новый файл без остальных модулей.

## Какую проблему решает

Автоматизирует ручной отбор модулей и сокращает время работы с таблицей при подготовке коммерческих предложений.

## Для кого

Для аккаунт-менеджеров, которые работают с таблицей модулей и готовят коммерческие предложения.

## Дорожная карта

1. Выбрать модуль в Excel-таблице.
2. Сформировать расчёт по выбранному модулю.
3. Сохранить расчёт в новый файл, удалив остальные неиспользуемые модули.
