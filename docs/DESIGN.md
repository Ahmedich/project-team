# Cosmos — стиль прототипа

Источник: [Cosmos на Refero Styles](https://styles.refero.design/style/eb804e3a-1b75-446c-8374-114bbabaf0cd)

Стиль выбран в комментарии к [задаче №14](https://github.com/Ahmedich/project-team/issues/14#issuecomment-5145952417).

## Направление

Светлый редакционный интерфейс на тёплом льняном фоне. Интерфейс остаётся монохромным и спокойным: визуальная иерархия строится на типографике, воздухе, белых поверхностях и тонких границах, а не на цветных акцентах и тенях.

## Цвета

| Роль | Значение |
| --- | --- |
| Фон страницы, Linen Canvas | `#f7f5f3` |
| Основной текст, Ink Black | `#0d0d0d` |
| Поверхность, Paper White | `#ffffff` |
| Вторичный текст, Stone | `#6e6a69` |
| Подсказки, Pebble | `#9a9796` |
| Границы | `#0d0d0d` с прозрачностью 10–15% |

## Типографика

- Основной характер — лёгкий контрастный serif.
- Использовать `Georgia` как доступную локальную замену cosmosOracle.
- Заголовки: вес 350–400, плотный межбуквенный интервал, короткая высота строки.
- Текст: 14–18 px, вес 400.
- Кнопки и подписи: вес 500.
- Не использовать жирность выше 500.

## Форма и ритм

- Максимальная ширина содержимого: 1280 px.
- Базовый радиус карточек, полей и кнопок: 16 px.
- Плавающая навигация: полный pill-радиус.
- Основной шаг отступов: 24 px.
- Поверхности плоские: без градиентов и теней.

## Компоненты прототипа

- Плавающая белая pill-навигация с точечным знаком.
- Центрированный редакционный заголовок сценария.
- Белая форма расчёта с тонкой полупрозрачной границей.
- Основная кнопка: Ink Black, белый текст, радиус 16 px.
- Вторичная кнопка: белая, тонкая Ink Black граница, те же размеры.
- Поля: радиус 16 px, спокойная нейтральная поверхность, чёрная focus-граница.
- Результат: плоский сокращённый документ с теми же токенами.

## Ограничения

- Не добавлять цветные акценты в элементы управления.
- Не использовать чистый `#000000`.
- Не использовать градиенты и тени.
- Не смешивать радиусы: 16 px для интерфейса, полный pill только для навигации и статусов.
- Не менять основной сценарий из `docs/UX.md` ради оформления.
