# Дизайн прототипа

## Выбранный стиль

[Apple (España) — Cathedral of white space](https://styles.refero.design/style/c9cabb96-32fa-4896-837a-f2497ce1c856) в Refero Styles.

## Обязательные правила

- Стили только через Tailwind CDN.
- Свои CSS не писать.
- Оформлять `index.html` по выбранному стилю Refero.

## Характер

Светлый, просторный и спокойный рабочий интерфейс. Иерархию создают крупные заголовки, свободное пространство и чередование белых и светло-серых поверхностей. Тени и декоративные градиенты не используются.

## Цвета

| Роль | Цвет |
| --- | --- |
| Основной текст | `#1d1d1f` |
| Вторичный текст | `#707070` |
| Основной фон | `#ffffff` |
| Альтернативный фон | `#f5f5f7` |
| Поднятая поверхность | `#fafafc` |
| Слабая граница | `#d6d6d6` |
| Главное действие | `#0071e3` |
| Ссылка и фокус | `#0066cc` |
| Ошибка | `#b64400` |

Синий `#0071e3` используется только для главного действия. Остальные элементы интерфейса остаются монохромными.

## Типографика

- Основной шрифт: Inter как доступная замена SF Pro.
- Заголовок страницы: 28–32 px, насыщенность 600.
- Заголовок секции: 17–21 px, насыщенность 600.
- Основной текст: 15–17 px, насыщенность 400.
- Подписи и метаданные: 12–14 px, цвет `#707070`.
- Размер шрифта не зависит от ширины viewport, межбуквенный интервал — обычный.

## Геометрия и ритм

- Максимальная ширина рабочего пространства: около 1200 px.
- Базовый шаг: 4 px; основные интервалы — 8, 16, 24 и 28 px.
- Основные панели: радиус 28 px, без внешней тени.
- Поля и группы выбора: радиус 12–16 px.
- Кнопки: pill-форма.
- Разделение крупных зон: смена фона вместо рамки.

## Компоненты

- Главное действие: синяя pill-кнопка с белым текстом.
- Вторичное действие: белая или прозрачная pill-кнопка с нейтральной границей.
- Поле: светло-серая поверхность, нейтральная граница, синий фокус.
- Рабочая панель: белая поверхность с радиусом 28 px и без тени.
- Метки шага: нейтральные круглые индикаторы без акцентного цвета.
- Иконки: монохромные линейные Lucide.

## Применение к прототипу

- Первый экран остаётся рабочей формой без маркетингового hero-блока.
- Итог закреплён справа на широком экране и расположен после формы на мобильном.
- Секции формы чередуют белую и едва заметную серую поверхность.
- Экран результата показывает только выбранные позиции и одно главное действие — скачивание `.xlsx`.
- Широкая таблица прокручивается внутри контейнера и не расширяет мобильный viewport.
