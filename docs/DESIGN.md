# Дизайн прототипа

## Выбранный стиль

[Linear — midnight precision instrument](https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1) в Refero Styles.

## Характер

Тёмный компактный рабочий интерфейс, в котором иерархию создают уровни поверхности и тонкие границы. Декоративные элементы, градиенты и объёмные тени не используются. Главный визуальный акцент всегда совпадает с главным действием экрана.

## Цвета

| Роль | Цвет |
| --- | --- |
| Фон страницы | `#08090a` |
| Основная поверхность | `#0f1011` |
| Поднятая поверхность | `#161718` |
| Граница | `#23252a` |
| Усиленная граница | `#383b3f` |
| Основной текст | `#e5e5e6` |
| Вторичный текст | `#8a8f98` |
| Главное действие | `#e4f222` |
| Успешное состояние | `#27a644` |
| Ошибка | `#eb5757` |

Кислотно-лаймовый `#e4f222` используется только для одного главного действия на экране. Остальные действия нейтральные.

## Типографика

- Основной шрифт: Inter с системным `sans-serif` как запасным вариантом.
- Заголовок страницы: 24 px, насыщенность 600.
- Заголовки секций: 16 px, насыщенность 600.
- Основной интерфейсный текст: 14–16 px.
- Метаданные и подписи: 12–13 px, цвет вторичного текста.
- Технические метаданные и имена файлов можно показывать моноширинным шрифтом.

## Геометрия и ритм

- Базовый шаг: 4 px.
- Основные интервалы: 8, 12, 16 и 24 px.
- Поля и кнопки: радиус 6 px.
- Панели: радиус не больше 8 px.
- Разделение поверхностей: тонкая граница вместо внешней тени.
- Максимальная ширина рабочего пространства: 1200 px.

## Компоненты

- Главное действие: лаймовая заливка, тёмный текст, высота 40–44 px.
- Вторичная кнопка: прозрачная или тёмная поверхность с тонкой серой границей.
- Поле: поверхность `#161718`, граница `#383b3f`, светлый текст; в фокусе граница `#e4f222`.
- Метка состояния: компактная прямоугольная плашка с радиусом 4 px.
- Рабочая панель: поверхность `#0f1011` и граница `#23252a`, без внешней тени.
- Иконки: минимальные линейные Lucide, без самостоятельного декоративного цвета.

## Применение к прототипу

- Форма расчёта остаётся основным рабочим экраном без маркетингового блока.
- Итог закреплён справа на широком экране и следует после формы на мобильном.
- Экран готового документа сохраняет ту же плотность и уровни поверхности.
- Таблица результата показывает только выбранные позиции.
- Адаптивная версия не создаёт горизонтальную прокрутку страницы; широкая таблица прокручивается только внутри своего контейнера.

## Техническое ограничение

Стили задаются только утилитарными классами Tailwind CDN внутри единственного корневого `index.html`. Собственный CSS не добавляется.
