# Автоматизация подготовки расчёта по модулям и опциям

## Что создаём сегодня

Делаем прототип одного основного сценария из `docs/UX.md`: аккаунт-менеджер открывает Excel, проходит путь расчёта и получает сокращённый итоговый файл без лишних модулей и лишней информации.

## Для кого

Для аккаунт-менеджеров, которые готовят коммерческие предложения в Excel и хотят быстро собрать корректный расчёт без ручной перегонки данных.

## Какую проблему решает

Убирает ручной и долгий сбор расчёта, снижает риск ошибок при переносе данных и помогает быстрее получить понятный итоговый Excel-документ.

## Признаки готовности

- Человек проходит путь из `docs/UX.md` до успешного выхода в прототипе.
- Успешный выход видно на экране.
- Прототип открывается локально в браузере.
- Прототип доступен по публичной ссылке деплоя.
- Основной сценарий из `docs/UX.md` можно выполнить без остановок и без ручного обхода.

## Ограничения на сегодня

- Один корневой `index.html` без других HTML-файлов и без папки `screens`.
- Открывается локально в браузере.
- Без базы данных.
- Данные можно хранить в `localStorage`.
- Стили только через Tailwind CDN.
- Свои CSS не писать.
- Без бэкенда, API и логина.
- Один основной сценарий из `docs/UX.md`.
- Репозиторий приватный; публична только ссылка деплоя.
